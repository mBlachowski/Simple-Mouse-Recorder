
# Simple Mouse Recorder

Simple Mouse Recorder is a lightweight tool for recording and replaying mouse movements and user inputs.


# Features

- Light and dark themes
- Polish and English language support
- Record and replay mouse movements and inputs


# Planned Features
- Schedule replays for a specific date and time
- Option to repeat a replay a specified number of times
# Disclaimer
Please be aware that this application does not attempt to hide itself in any way, either from users or from anti-cheat software.
