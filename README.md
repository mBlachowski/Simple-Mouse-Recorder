
# Simple Mouse Recorder

Simple Mouse Recorder is a lightweight tool for recording and replaying mouse movements and user inputs.


# Features

- Light and dark themes
- Support for Polish and English
- Record and replay mouse movements and inputs


# Planned Features
- Schedule replays for a specific date and time
- Dynamic translation
